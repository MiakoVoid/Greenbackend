# 绿芽记账（GreenFinance）项目详细设计文档

## 一、项目元信息
大学生毕业设计项目

| 字段     | 具体内容                                               |
|----------|--------------------------------------------------------|
| 项目名称 | 绿芽记账                                               |
| 项目定位 | 基于 AI 智能识别的个人财务管理安卓应用                 |
| 核心价值 | 通过云端 AI + 移动端交互，提供便捷的智能记账、财务分析服务，降低个人财务管理门槛 |
| 目标用户 | 需管理个人财务的学生、职场新人等（需建立财务规划习惯的群体） |

## 二、技术架构（分层明确）

### 1. 前端架构（Android 端）

#### 技术栈
- Android Native（Java）+ Material Design 3 + MVVM 架构

#### 核心能力
- 离线数据存储
- 本地图片管理（头像 / 分类图标）
- Material Design 3 风格 UI 渲染

### 2. 后端架构

#### 核心框架
- Spring Boot 2.7 + MyBatis-Plus 3.5

#### 数据库
- MySQL（存储用户、账单、分类、预算等数据）

#### 数据安全
- HTTPS 传输加密
- 敏感信息存储加密
- 用户数据隔离

### 3. AI 与识别服务

#### AI 模型
- 魔塔社区 Qwen2.5-7B-Instruct（用于文本解析、智能分类）

#### OCR 引擎
- Google ML Kit Text Recognition（用于截图文字提取）

#### AI 核心能力
- 消费记录智能分类（两级分类体系）
- 自然语言文本解析
- 支付渠道识别

### 4. 部署平台

#### 平台
- Render（免费套餐）

#### 部署能力
- Web 服务自动构建 / 部署
- 环境变量管理
- 日志监控

## 四、系统架构设计（前端分层 + 核心页面）

### 1. 安卓前端架构（四层模块化）

#### （1）界面层（用户交互入口）

- 认证模块：登录（带记住密码）、注册
- 首页模块：财务概览（今日支出 / 本月支出 / 本月收入 / 剩余预算）、预算管理、近期账单列表
- 账单管理模块：账单增删改查、账单详情展示
- 日历视图模块：月度日历（标记每日消费）、当日账单明细、快速定位今日
- 报表分析模块：支出趋势图、分类构成分析、分类排行、AI 财务建议
- 个人中心模块：用户信息展示、分类管理、分类关键词管理、数据导入 / 导出

#### （2）数据层

- 数据模型：定义业务实体结构（用户、账单、分类等）
- 数据仓库：统一数据访问接口（对接本地数据库 + 后端 API）
- 本地数据库：支持离线存储（账单、分类等基础数据）

#### （3）领域层

- 业务用例：封装核心逻辑（如账单计算、预算计算）
- 仓库接口：定义数据访问契约（解耦数据层与业务层）

#### （4）公共组件

- 通用 UI 组件：可复用元素（按钮、输入框、卡片）
- 工具类库：通用功能（日期处理、金额计算）
- 主题配置：全局主题（颜色、字体）管理

| 页面名称       | 核心设计 / 功能                                                                                                      |
|----------------|---------------------------------------------------------------------------------------------------------------------|
| 底部导航栏     | 布局：[首页] [日历] [中央悬浮按钮] [报表] [我的]；中央按钮：快捷记账入口（弹出 3 种记账方式）                         |

## 五、核心功能特性（流程 + 规则清晰）

### 1. 三种记账方式（场景全覆盖）

#### （1）手动选择记账

- 流程：选择收支类型→选两级分类→输入金额（原始 + 退款）→填商户 / 备注→选时间→保存
- 关键规则：用户输入新分类时，自动创建分类；提供最近使用分类快速选择

#### （2）截图记账

- 截图获取：系统截图监听自动触发 / 手动上传图片
- AI 能力：识别支付渠道（微信 / 支付宝 / 美团等）、提取商户 / 商品明细、匹配两级分类（仅用现有分类）
- 流程：截图→OCR 识别→AI 解析→结果预览→用户确认 / 修改→保存（修改分类时自动创新分类）

#### （3）文本记账

- 输入：自然语言描述（如 "今天下午 2 点在肯德基花 45 元,咖啡15r，奶茶16元，今天吃了kfc"）
- AI 能力：实时解析金额、时间、商户、分类（仅用现有分类）
- 流程：输入文本→AI 解析→结果预览→用户确认 / 修改→保存（修改分类时自动创新分类）

### 2. 智能记账核心规则

#### （1）智能记账确认流程
//该用户第一次的时候可以选择是否弹出显示，1.永不。2.总是。

```
AI识别/解析 → 根据系统配置项是否需要弹出显示结果预览页面 → 用户确认（直接保存）/ 修改（字段调整）→ 保存账单
↓（若用户修改分类）
分类不存在？→ 是→自动创建分类→继续保存；否→直接保存。不存在就直接保存
```

#### （2）条件性分类自动创建规则（保护分类库整洁）

- AI 识别 / 解析时：仅用现有分类，不自动创建新分类
- 用户手动操作时：
  - 手动记账输入新分类→自动创建
  - 智能记账（截图 / 文本）中修改为新分类→自动创建

### 3. 两级分类体系（固定主分类 + 可扩展子分类）

- 主分类（固定 8 个）：餐饮、交通、购物、娱乐、医疗、教育、生活、其他
- 子分类（主分类下细分）：如 "餐饮→快餐 / 奶茶 / 正餐 / 零食"
- 扩展规则：用户可自定义添加子分类，或添加新主分类

### 4. 预算管理功能

- 预算模型：剩余预算 = 月度预算 - 实际支出 - 待支付预计支出
- 核心能力：月度预算设置、预算进度监控、预算预警（超支提示）

## 六、AI 智能功能（流程 + 能力明确）

### 1. OCR 识别流程（截图记账核心）

1. 图像获取：相机拍摄 / 相册选择 / 系统截图监听/悬浮球
2. 文字提取：Google ML Kit Text Recognition 提取图片文本
3. 数据解析：正则表达式匹配金额、时间、商户等关键字段
4. 智能分类：结合关键词 + Qwen2.5-7B 模型匹配两级分类（仅用现有分类）
5. 结果返回：结构化数据（金额、分类、商户、时间等）供前端预览
6. 最终确认：用户修改后保存（修改分类时触发新分类创建）

### 2. 文本解析流程（文本记账核心）

1. 文本输入：用户输入自然语言描述（如 "10 月 25 日微信付喜茶 35 元"）
2. 智能解析
3. 根据结果分类是预计支出还是已经支出，然后创建对应项

### 3. AI 财务建议能力

- 输入：用户月度账单数据（支出 / 收入 / 分类分布）
- 输出：个性化建议（如 "餐饮支出占比 35% 过高，建议控制快餐频率"）
- 依据：用户历史消费数据、分类支出占比、预算使用情况

## 七、核心技术特性（价值可量化）

1. 智能预算管理：动态计算剩余预算，避免超支（核心模型：剩余预算 = 月度预算 - 实际支出 - 待支付预计支出）
2. 多维度分析：支持时间（日 / 周 / 月 / 年）、分类、支付渠道 3 类维度分析，提供数据洞察
3. 本地 + 云端混合架构：本地存储保障离线可用，云端 AI 提升智能能力
4. 数据安全：HTTPS 传输 + 敏感信息加密 + 用户数据隔离，保障隐私
